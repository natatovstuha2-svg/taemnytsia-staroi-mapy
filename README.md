# Таємниця старої мапи — інтерактивна книга

Готовий статичний сайт для GitHub Pages. Усі текстові сторінки вже є зображеннями; браузер нічого не переверстує.

## Структура
- `index.html` — сторінка книги
- `styles.css` — адаптивна сцена, безпечні поля, тінь
- `app.js` — порядок сторінок і м’яке перегортання
- `assets/pages/` — готові сторінки 2:3

## Публікація на GitHub Pages
1. Завантажити весь вміст цієї папки в корінь репозиторію.
2. У GitHub: **Settings → Pages**.
3. **Build and deployment → Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)` → **Save**.

Книга використовує StPageFlip 2.0.7 через jsDelivr CDN.
